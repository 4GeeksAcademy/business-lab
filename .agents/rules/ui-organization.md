# Organización de interfaces

## Alcance

Esta regla se aplica al crear o modificar archivos en:

- `uis/website/**`
- `uis/backoffice/**`

## Instrucciones

- Mantén separados el diseño público del website y el diseño interno del backoffice, con una identidad visual coherente para Nexova.
- Usa contenido respaldado por `CONTEXT.md`. No inventes hechos sobre Nexova.
- No introduzcas datos ficticios sin autorización del usuario. Si se autorizan, identifícalos claramente como datos de demostración.
- Reutiliza componentes cuando haya elementos repetidos. No crees una biblioteca adicional como parte de esta tarea.
- Documenta en el README de cada aplicación su propósito, tecnología y pasos de ejecución.
